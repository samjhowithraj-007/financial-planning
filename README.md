# Financial Planning — Samjho with Raj

**Middle-Class Family Ka Money Plan:** a 50-part Hindi/Hinglish video series on budgeting, safety, debt, investing,
home, education and retirement for middle-class Indian families.

| Path | What |
|---|---|
| [Financial-Planning-Project.md](Financial-Planning-Project.md) | Series plan: rules, 50-episode roadmap, example budget, episode template |
| [episodes/](episodes/) | One script per episode: brief, continuity, calculations, talking points, storyboard, Short, packaging |
| [videos/](videos/) | Video projects per episode (recording notes, edit files); footage and renders are not stored here |
| `hyperframes-whisper/`, `build_video_plugin.py`, `*.mjs` | Personal HyperFrames + Whisper video plugin and its build/verify scripts |

All family scenarios are illustrative teaching examples, not financial advice.
